FM26 AI MANAGER V0.6 - PORTABLE DIAGNOSTIC
==========================================

NO PYTHON / NO INSTALLER / NO .BAT REQUIRED FOR USE.

FIRST TEST
1. Extract the ZIP to a normal folder (for example Desktop\FM26_AI_MANAGER_V0.6_PORTABLE).
2. Open Football Manager 2026 and load your save.
3. Prefer Windowed or Borderless mode for the first diagnostic.
4. Double-click FM26_AI_MANAGER.exe.
5. Confirm that FM26 shows DETECTED.
6. Click EXPORT DIAGNOSTIC.
7. For richer calibration, open each screen in FM26 and use the matching TRAIN button:
   HOME / PORTAL, SQUAD, PLAYER PROFILE, FINANCES.
8. Send the generated diagnostics folder and logs folder back in ChatGPT.

SAFETY
V0.6 is READ-ONLY. It does not send mouse clicks or keyboard input and does not modify the FM26 save.
